## 1. 测试目标

验证客户端满足需求规格的 16 条验收标准（AC-01~16），重点覆盖：

1. 与云平台（R1 MXS V2.1.2）的 12 类包协议一致性（AC-02/03/04/05/06/07）。
2. 连接/重连/遗嘱/3min 无下行策略（AC-08/09/10）。
3. 交叉编译产物在 RV1106 实机可运行（AC-11）与 72h 长稳（AC-12）。
4. 资源占用达标（AC-13）、单测全绿且覆盖率 ≥ 80%（AC-14）、本地 Broker 集成联调（AC-15）、负向不崩溃（AC-16）。

## 4. L2 协议一致性测试（Mock）

在 Host 用内存 Channel 替代真实传输，构造 R1 各包样例断言：

- 上行包字段顺序、命名、单位与 `MQTT 客户端数据流与命令清单.md` / `MXS MQTT 通信协议（V2.1.2）.md` 完全一致。
- 下行包（login/print/control/file_* 等）解析正确，未知 cmd/缺字段/类型错误均返回错误且不 panic。
- 重点回归：
  - `printState` 枚举 0 空闲/1 打印/2 完成/3 暂停/4 失败/5 取消 与 R1 §5.3 一致。
  - `bindState`：`bound = (bind_state == 0)`（0 已绑定/1 未绑定/2 未录入），R1 §5.1。

## 5. L3 集成测试（本地 Broker）

环境：本地 `mosquitto` 或 `emqx`，开启匿名/账密。

| 场景 | 步骤 | 期望 |
| --- | --- | --- |
| 连接登录 | 启动客户端连本地 Broker | 收到 `login:1` 应答（AC-01） |
| 状态上报 | 模拟 Klipper 状态变化 | Broker 收到 status_temp_fan/status_print 等（AC-02） |
| GCODE 下发 | 发布 M20/M115 等下行 | 客户端回 result 包，`gcode_seq` 正确关联（AC-03） |
| 文件下载 | 触发 download_begin/end | 文件落盘且校验通过（AC-04） |
| 固件/列表/解绑 | 对应下行 | upgrade_query/file_list/server_unbind 流程完成（AC-05/06/07） |

工具：用 Python `paho-mqtt` 脚本模拟云端，校验客户端上下行报文。

## 6. L4 系统/实机测试（RV1106）

交叉编译：`scripts/build.sh release`（产出 `target/armv7-unknown-linux-gnueabihf/release/mqtt-client`，ELF 32-bit uclibc）。

| 场景 | 操作 | 期望（AC） |
| --- | --- | --- |
| 交叉编译可运行 | `./scripts/build.sh release` + scp 到板 | 二进制在 RV1106 运行（AC-11） |
| 自动重连 | 拔网线 / 重启 Broker | 自动重连并重新登录，业务恢复（AC-08） |
| 遗嘱 | 异常掉线（kill -9） | Broker 收到 LWT（AC-09） |
| 3min 无下行 | 云平台停止下发 | 按 R2 触发重连/重新登录（AC-10） |
| 72h 长稳 | 实机连续运行 | 无崩溃、无内存增长（RSS 监控）、无不可恢复断连（AC-12） |
| 资源 | `top`/`free` 采样 | 满足 NFR-PERF-04/05（AC-13） |

监控：`RSS` 每 10min 采样，绘制曲线；CPU 峰值在打印 GCODE 下发时采样。

## 7. L5 负向/异常测试（AC-16）

| 注入故障 | 期望 |
| --- | --- |
| 非法 JSON 下行 | 解析失败告警，不 panic，连接保持 |
| 超长消息（>1024B） | 截断/拒绝，不崩溃 |
| 未知 cmd | 忽略并告警，不崩溃 |
| Broker 异常关闭 | 触发重连逻辑，不崩溃 |
| MQTT 认证失败 | 报告错误并符合条件退出/重连，不 panic |
| Moonraker WS 断开 | 降级/重试，主循环不崩溃 |
